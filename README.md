# Atelier P2P

AI for procure-to-pay in luxury retail, from invoice PDFs to validated data, quality checks,
and a text-to-SQL copilot.

1. **Extraction**: messy invoice PDFs to validated, structured data, with a human review queue
2. **Warehouse**: SAP-style staging and marts with dbt + DuckDB
3. **Quality agent**: three-way match, duplicates, anomalies, root-cause explanations, proposed tests
4. **Analytics copilot**: text-to-SQL over a semantic layer, with a golden-set evaluation

Every stage is measured. Results go here as they are produced.
